Start here

Voxt Mobile is a voice keyboard for iPhone: Voxt on this Mac turns what you say into text. You need a Mac with Apple silicon running macOS 26.2 or later, and an iPhone with iOS 17 or later.

On this Mac

  1. Install.

    Voxt Omni Dev runs the speech and text models; Voxt Connector links your iPhone to it.

    In the window this guide came in, drag Voxt Omni Dev and Voxt Connector onto the Applications folder. Voxt Omni Dev is Voxt with the phone feature.
  2. Open Voxt Omni Dev and decide on the permissions.

    Phone dictation uses neither permission, because its audio comes in through the Local API; Voxt uses the microphone to record on the Mac, and Accessibility for its keyboard shortcuts and to type into Mac apps.

    Open it from Applications. macOS may show Accessibility Access: “Voxt Omni Dev would like to control this computer using accessibility features.” Then Voxt’s setup guide opens at Get Permissions.
    • To dictate on the Mac too: click Open System Settings in that message and switch Voxt Omni Dev on. In the setup guide, click Allow next to Microphone Permission and Accessibility Permission, then Continue.
    • For the phone only: click Deny, and close the setup guide with its × button. The guide moves on only after both are allowed.
  3. Download a speech model and a text model.

    The models run on this Mac and are downloaded once.

    Choose these two:
    • Qwen3 1.7B (6bit), about 2.0 GB, for speech. It is accurate in many languages and shows the words while you speak.
    • Qwen3.5 4B OptiQ (4bit), about 3.0 GB, for text. It turns what you said into clean text.
    In the setup guide, at Choose Models, keep Local and click Install next to the first under Speech-to-text Model (click More if it is not listed) and next to the second under Translation (Optional). Click Continue when the downloads finish; you can close the guide after that, as its next pages practise dictation on the Mac.
    With the setup guide closed: click the Voxt icon in the menu bar, choose General, then Model, and click Install next to the first under ASR and next to the second under LLM.
    Other local models in these lists work too; the larger ones need a Mac with more memory.
  4. Use the two models for dictation.

    Phone dictation uses the same Transcription settings as dictation on the Mac.

    Click the Voxt icon in the menu bar, choose Feature, then Transcription. Set Speech Model to Qwen3 1.7B (6bit). Turn on Text Enhancement and set Enhancement Model to Qwen3.5 4B OptiQ (4bit).
  5. Turn on the Local API.

    It lets Voxt Connector reach Voxt on this Mac only (127.0.0.1); it is off by default and opens nothing to the internet.

    Click the Voxt icon in the menu bar and choose General. Under Local API, turn on Allow other apps to dictate through Voxt.
  6. Open Voxt Connector and let it connect to Voxt.

    Voxt gives its port and access token only to a Voxt Connector signed by the same developer as Voxt.

    Open it from Applications; it stays in the menu bar. Its Set up window lists these same steps and ticks each one off when it sees it done. Click Connect. Voxt Omni Dev asks Allow Voxt Connector to use Voxt? Click Always Allow.
  7. Click Add iPhone.

    Only phones you add can connect, over an end-to-end encrypted link; each code adds one phone and expires in two minutes.

    Voxt Connector shows a QR code. Leave it open for the iPhone.

On your iPhone

  1. Install the beta.

    The iPhone app is in public beta, so it comes through Apple’s TestFlight app.

    Scan this code with the iPhone Camera, or open testflight.apple.com/join/ddn8Mz84 on the iPhone. Install TestFlight if it asks, then install Voxt.
  2. Open Voxt and add the keyboard.

    iOS keyboards can’t use the microphone, so with Full Access the keyboard asks the Voxt app to record.

    The app shows each step: add the Voxt keyboard in Settings, then turn on Allow Full Access.
  3. Scan the QR code on your Mac.

    The QR code pairs this iPhone with your Mac.

    At Connect your Mac, point the iPhone at the QR code in Voxt Connector. The app then shows your Mac as Connected.

Try it

In any app, switch to the Voxt keyboard, tap the mic and speak.
The text appears where you were typing.
